# Nightbloom Modpacks

Die offiziellen Modpacks für den Minecraft-Server Nightbloom (`play.nightbloom.site`), Minecraft 26.3 mit Fabric. Beide enthalten nur Mods aus der Mod-Whitelist.

| Pack | Für | Download |
| --- | --- | --- |
| **Nightbloom Low** | schwächere PCs und Laptops, mehr FPS | [nightbloom-low.mrpack](https://github.com/1sythe/nightbloom-modpacks/releases/latest/download/nightbloom-low.mrpack) |
| **Nightbloom High** | Gaming-PCs, mit Shadern und weiter Sicht | [nightbloom-high.mrpack](https://github.com/1sythe/nightbloom-modpacks/releases/latest/download/nightbloom-high.mrpack) |

## Installieren

**Modrinth App:** Datei herunterladen, in der App auf das Plus (Instanz hinzufügen) klicken, "Aus Datei importieren" wählen und die `.mrpack`-Datei auswählen. Oder die Datei einfach auf das Fenster der App ziehen.

**Prism Launcher:** "Instanz hinzufügen", links "Importieren", die `.mrpack`-Datei auswählen.

Die Mods lädt der Launcher selbst von Modrinth herunter. Nightbloom ist in der Serverliste schon eingetragen.
